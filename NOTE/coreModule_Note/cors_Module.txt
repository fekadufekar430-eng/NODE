


What is CORS?


CORS stands for Cross-Origin Resource Sharing.

 By default, web browsers have a security feature called the Same-Origin Policy.
 This policy prevents a frontend application running on one port or domain 
 (for example, at http://localhost:5173) from fetching data from a backend server
  running on a different port (for example, at http://localhost:3000).

In short, if your frontend and backend are hosted on different origins, 
the browser blocks them from exchanging data for security reasons.

What does the cors module do in Node.js?
The cors module is a middleware we use in our server that adds the necessary HTTP headers
(Access-Control-Allow-Origin, etc.) to the server's responses.

This tells the browser: "It's safe; you can accept requests coming from a different origin."

Code Example
How to use it in a Node.js and Express application:

JavaScript
const express = require('express');
const cors = require('cors'); // Import the cors module

const app = express();

// 1. Enable CORS for all origins (Simple setup)
app.use(cors());

// Test route
app.get('/api/data', (req, res) => {
    res.json({ message: "Hello john! CORS is working correctly." });
});

app.listen(3000, () => {
    console.log("Server is running on http://localhost:3000");
});
Best Practice (For Production)
In real-world projects, allowing every single website to access your server is not secure.
 Therefore, we can restrict communication to only trusted frontend URLs:

JavaScript
const corsOptions = {
    origin: 'http://localhost:5173', // Allow only this specific frontend
    methods: ['GET', 'POST'],        // Allow only these methods
};

app.use(cors(corsOptions));

In short:
        Without the CORS module, your frontend application cannot 
        fetch or send data to your backend server (the browser will block it with a security error).
